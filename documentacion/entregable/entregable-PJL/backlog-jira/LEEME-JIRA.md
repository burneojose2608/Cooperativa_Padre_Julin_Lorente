# Respaldo local y presentación directa de Jira

Se incluyen el `product_con_subtareas.csv` original, `sprint_1_planificado.csv` y `conciliacion_sprint_1.csv`. El CSV original conserva tipos, padres, prioridades, estimaciones, responsables, estados y sprints; no se modificaron asignaciones ni se marcaron tareas como terminadas por inferencia.

**El usuario presentará el backlog directamente al profesor desde Jira.** Por su indicación, no se requiere aportar el enlace ni realizar una comprobación remota como parte de esta carpeta. Los CSV se conservan únicamente como respaldo local. Los Work item ID del CSV no se presentan como claves remotas del tipo PROY-123.

La presentación directa del usuario cubre la evidencia externa de Jira prevista para la revisión. No se solicita una nueva importación del CSV ni se cambian estados remotos desde esta entrega.

El subconjunto planificado contiene las historias consolidadas HU-001 y HU-009 y sus cinco subtareas HU-006, HU-008, HU-010, HU-012 y HU-015. Las siete referencias conservan trazabilidad, pero no se cuentan como siete historias independientes al sumar esfuerzo. Las tareas transversales y su alcance se documentan en sprint-1/plan-sprint-1-equipo.md.

Las pruebas locales aprobadas se acreditan en sprint-1/verificacion-actual.md. El cierre del sprint remoto y la aceptación del docente siguen siendo hechos externos que no se simulan mediante un CSV.
